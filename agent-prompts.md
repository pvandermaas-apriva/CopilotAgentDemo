# Agent Prompts

Use these prompt templates with GitHub Copilot agents and customize as needed.

## Prompt Library
- [Feature implementation prompt](.github/prompts/feature-implementation.prompt.md)
- [Test generation prompt](.github/prompts/test-generation.prompt.md)
- [Documentation update prompt](.github/prompts/documentation-update.prompt.md)

## Suggested Workflow
1. Start with the feature prompt.
2. Run the test prompt after code changes.
3. Run the documentation prompt before merging.

## Notes
- Keep prompts specific (files, expected behavior, constraints).
- Ask for minimal diffs and adherence to existing patterns.
