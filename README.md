# CopilotAgentDemo

### Leverage features of GitHub Copilot cloud agents linked to a GitHub repository. ###
---

A simple **Blazor Web App** template to be built upon using *GitHub Copilot cloud agents* to demonstrate various uses and productivity gains. 

The agent will be used to generate code, tests, documentation, and more based on the prompts provided in the `agent-prompts.md` file, as well as additional markdown files supported by the agent.

## Features
 - .NET 10
 - C# 14
 - [Aspire 13.1](https://aspire.dev/) Orchestration (also assists Copilot agents!)
